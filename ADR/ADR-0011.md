# ADR-0011 — Visão: imagem para o LLM multimodal + captura de tela (OnDemand)

- **Status:** **Aceito**
- **Data:** 2026-08-10

## Contexto
A Fase 8 dá visão à Friday: enviar uma imagem (upload) ou a tela do Host e
perguntar sobre ela, respondida por um modelo multimodal local.

## Problema
- O LLM de texto (`llama3.1:8b`) não vê imagens; é preciso um modelo de visão.
- A captura de tela é do Host (o browser/WebView não acessa a tela do SO por conta
  própria) — pertence à camada de percepção como um sensor.
- Restrição do manifesto: tudo local, sem chave.

## Decisão
- **Imagem → LLM de visão via Ollama:** a `ChatMessage.images` (base64) já existia;
  o provedor Ollama já a encaminha. Quando a mensagem tem imagem, o
  `ConversationService` usa `FRIDAY_VISION_MODEL` (default `llava`, trocável) e
  **pula o RAG** (a pergunta é sobre a imagem, não a web). Sem modelo de visão
  instalado, degrada com erro claro (o usuário roda `ollama pull llava`).
- **Captura de tela = `ScreenCaptureSensor` (OnDemand)** via `mss` (+`Pillow`),
  emitindo `Percept(SCREEN, image/png)`. Exposto por `GET /api/vision/screen`
  (base64) e por `SensorManager.snapshot()` (captura sem enfileirar).
- **Frontend:** botões de anexar imagem (upload → base64) e capturar a tela; a
  imagem vai com a próxima mensagem e é exibida na conversa.

## Justificativa
- Reusa a porta de LLM e a camada de sensores já desenhadas (mínimo de código novo).
- 100% local; o modelo de visão é uma escolha de configuração.

## Impactos
- **Backend:** `settings` (`vision_enabled`, `vision_model`); `conversation`/`rag`
  (imagens + seleção do modelo + pular RAG); `perception/sensors/screen.py`;
  `SensorManager.snapshot`; `api/rest/vision.py`; registro no lifespan.
  Deps: `mss`, `Pillow`.
- **Frontend:** upload/captura, `pendingImage`, envio com `images`, exibição.
- **Limitações / evolução:** webcam (StreamingSensor via opencv) e OCR dedicado
  (tesseract) ficam para incrementos futuros — a visão do LLM já lê texto em
  imagens. A captura pega o monitor primário (multi-monitor é config).
